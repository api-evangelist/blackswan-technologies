## Open source (BST LABS — BlackSwan Technologies software engineering unit)

- [BST LABS on GitHub](https://github.com/BstLabs): the CAIOS (Cloud AI Operating System) team's open source repositories
- [DynaCLI](https://github.com/BstLabs/py-dynacli): converts pure Python functions into Linux shell commands — `pip install dynacli`
- [DynaCLI documentation](https://bstlabs.github.io/py-dynacli/): tutorial, reference manual and advanced reference
- [CLVM](https://github.com/BstLabs/py-clvm): cloud VM command line tool for AWS, Azure and GCP — `pip3 install pyclvm`
- [PyJdict](https://github.com/BstLabs/py-jdict): JavaScript-like Python dictionary — `pip install pyjdict`
- [PyComposite](https://github.com/BstLabs/py-composite): Composite design pattern as a Python class decorator — `pip install pycomposite`
- [AuthK](https://github.com/BstLabs/py-authk): SSHD authorized_keys handling utility — `pip install authk`
